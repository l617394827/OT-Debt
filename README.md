# OT-Debt · 加班清算单

> 把深夜消息、临时修改和漫长等待，清算成一张有证据、有数字、也有脾气的账单。

OT-Debt 是一个使用 TypeScript 构建的纯前端小工具。它不会只告诉你“加了多少班”，而是尝试分辨哪些时间花在了等待、临时需求、反复修改和非工作时段会议上，并生成一份可查看、可沟通、可分享的加班清算单。

## 为什么做这个项目

大多数加班工具解决的是“记工时”，OT-Debt 更关心“这笔班为什么会发生、是否值得发生”。

- 让散落在聊天记录里的隐形付出被看见
- 区分必要处置与流程、沟通造成的无效加班
- 把模糊的疲惫转成时间、金额和生活损耗
- 用不同语气把同一组事实整理成可沟通的话
- 帮助使用者重新确认自己的工作与生活边界

## 功能特性

- 粘贴聊天记录，按日期、时间和关键词提取加班线索
- 拖入 `.txt` 或 `.csv` 文件进行解析
- 手动补录日期、起止时间、原因与证据
- 自动区分无效加班和必要处置
- 计算总时长、无效占比、折算金额与班味浓度
- 支持“毒舌满格”“据理力争”“体面辞职”三种口吻
- 一键复制沟通话术
- 打印完整清算单
- 下载 9:16 PNG 分享卡片
- 无账号、无后端、无数据持久化

## How to Use

### 1. 安装与启动

环境要求：

- Node.js 18 或更高版本
- npm 9 或更高版本

克隆项目并安装依赖：

```bash
git clone <your-repository-url>
cd OT-Debt
npm install
```

启动开发服务：

```bash
npm run dev
```

终端会显示本地访问地址，通常为：

```text
http://localhost:5173/
```

### 2. 准备加班记录

你可以任选一种方式，也可以混合使用。

#### 方式 A：直接粘贴聊天记录

将带有日期、时间和工作内容的聊天片段粘贴到“聊天记录”输入框。例如：

```text
2026-09-03 21:30 产品同事：首页按钮再换个橙色，明早要看
2026-09-03 23:00 我：第六版已经发了
2026-09-10 20:00 项目群：先等审批，稍后再给排期
2026-09-10 22:30 我：审批还没下来
```

当前规则会重点寻找以下信息：

- 日期：`2026-09-03`、`2026/09/03` 或 `09-03`
- 时间：`21:30`、`23:00`
- 工作线索：紧急、需求、修改、等待、审批、会议、故障、上线、`@` 等

#### 方式 B：拖入聊天文件

将 `.txt` 或 `.csv` 文件拖到上传区域，或点击该区域选择文件。

- 单个文件建议不超过 2 MB
- 建议只保留需要清算的聊天片段
- 文件中最好同时包含日期、时间和工作内容

#### 方式 C：手动补录

在“手动补一笔”区域依次填写：

1. 加班日期
2. 开始与结束时间
3. 加班类型
4. 一句证据或说明

点击“记入这笔账”后，可以继续添加下一笔记录。录错的条目可在待清算列表中删除。

### 3. 设置折算时薪

在页面底部填写用于估算时间价值的时薪。清算单会根据无效加班时长计算“无偿垫付”金额。

该金额只用于个人记录和沟通参考，不代表法定加班费计算结果。

### 4. 生成清算单

点击“开始清算”。页面会生成：

- 本月加班总时长
- 无效加班时长与占比
- 无偿垫付金额
- 班味浓度与等级
- 每笔加班的证据和清算意见
- 电影、晚饭、睡眠等人生损耗换算

如果没有识别出记录，请检查输入是否同时包含时间和工作关键词，或改用手动补录。

### 5. 切换表达方式

清算单顶部提供三种口吻：

| 模式 | 适用场景 |
| --- | --- |
| 毒舌满格 | 自己解气、朋友间分享、传播卡片 |
| 据理力争 | 与负责人沟通排期、调休或补偿 |
| 体面辞职 | 梳理离职表达与工作边界 |

切换模式后，逐条清算意见、诊断总结和复制话术会同步变化。

### 6. 导出结果

- **复制甩脸话术**：复制当前语气对应的完整沟通文案
- **下载 9:16 卡片**：生成适合手机分享的 PNG 图片
- **打印清算单**：调用浏览器打印功能，可另存为 PDF

## 输入识别说明

当前版本使用浏览器内的规则解析，并非完整的自然语言模型。为了获得更稳定的结果，建议：

- 每条消息保留明确的日期和时间
- 不要删除“修改”“审批”“会议”“故障”等上下文词
- 对识别不准或缺少结束时间的记录使用手动补录
- 生成后再次核对时长、类型和证据原文

必要线上事故会被标记为必要处置；等待、反复修改、非工作时间会议和临时安排通常会被判定为无效加班。

## 隐私与安全

- 聊天内容不会上传到服务器
- 项目没有账号系统和后端数据库
- 页面不会持久化保存输入内容
- 刷新或关闭页面后，当前记录会消失
- 分享前请自行检查并遮盖公司名、人名与业务信息

> 本项目是情绪疏导与个人记录工具，不构成法律、劳动仲裁、薪酬或医疗建议。重要证据请保留原始文件。

## 技术栈

- TypeScript
- Vite
- 原生 DOM API
- Canvas API
- CSS 响应式布局与打印样式

项目没有引入前端框架和 UI 组件库，便于快速运行、阅读与二次开发。

## 当前限制

- 解析依赖固定关键词，复杂聊天格式可能需要手动补录
- 未接入微信、钉钉或飞书 SDK
- 不支持自动读取历史聊天记录
- 无服务端存储和跨设备同步
- 分享卡片暂未提供自动打码功能
- 折算金额不等同于劳动法意义上的加班费
